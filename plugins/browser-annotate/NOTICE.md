# Browser Annotate

Используется и адаптировано для VesnALIA с разрешения автора (подтверждено владельцем проекта 16.11.2026).

- Оригинальный автор: Timur Khakhalev (https://github.com/timurkhakhalev)
- Исходный репозиторий: https://github.com/timurkhakhalev/timurkhakhalev-bb-plugins
- Каталог в репозитории: plugins/browser-annotate
- Версия: browser-annotate/v0.1.1, коммит c1a1a263256ab482347118b9b6248096ce5d8c5d
- Ссылка на исходник: https://github.com/timurkhakhalev/timurkhakhalev-bb-plugins/tree/c1a1a263256ab482347118b9b6248096ce5d8c5d/plugins/browser-annotate
- Лицензия: лицензия не указана в исходном репозитории

Изменения VesnALIA: манифест и зависимости переведены на движок alia-core
(раздел `alia`, `@vesnalia/plugin-sdk`), имена bb заменены на имена VesnALIA,
бренд BB в видимых текстах заменён на VesnALIA. Изменения сделаны скриптом
`scripts/adapt.mjs`; список ручных правок и состояние сборки - в STATUS.md.

Авторские права на исходный код принадлежат оригинальному автору.
