# Голосовой ввод VesnALIA

Плагин регистрирует голосовой сервис `local-voice`, и VesnALIA отдаёт ему записи из
чата. Распознавание идёт на выбранной машине: локальные движки сохраняют аудио локально, облачные отправляют его провайдеру.

## Включение

Голосовой сервис выбирается настройкой VesnALIA, а не плагином:

```
alia settings ai-services                     # список доступных сервисов
alia settings ai-services set voice local-voice
```

Дальше движок разворачивается на машине:

```
alia voice-input setup                 # ставит выбранный в настройках движок
alia voice-input setup gigaam          # конкретный движок
alia voice-input status                # что установлено и готово
```

Облачным движкам установка не нужна — только ключ в настройках (вкладка
«Облако»). `setup` ставит пакеты и может занять минуты; модель дозагружается при первом
распознавании. Для Whisper и GigaAM нужны Python 3 и ffmpeg на машине.

## Движки

| Движок | Чем считает | Когда выбирать |
| --- | --- | --- |
| `whisper` | mlx-whisper на Apple Silicon | Русский и смешанная речь, названия инструментов; выбор по умолчанию |
| `gigaam` | GigaAM v3 e2e (Сбер), torch на MPS | Сплошной русский: быстрее и с пунктуацией, но коверкает латиницу |
| `groq` | whisper-large-v3-turbo в облаке | Ставить нечего, есть бесплатный уровень; аудио уходит наружу |
| `openai` | gpt-4o-transcribe в облаке | Ставить нечего, точность высокая; аудио уходит наружу |
| `google` | gemini-3.5-transcribe в облаке | То же для Google; ключ из Google AI Studio |

## Настройки

Правятся в Settings → Installed plugins или через `alia plugin config voice-input`.

- **Движок**, **модель Whisper** (turbo быстрее, large-v3 точнее), **язык**
  (`auto` для смешанной речи, явный — для коротких фраз).
- **Словарь терминов** — простой список через запятую: `DeepSeek, Claude Code,
  env, VesnALIA`. Искажения перечислять не нужно: их находит починка по согласному
  костяку слова. Для упрямых случаев можно задать замену явно:
  `Claude Code = клодкод`.
- **Клавиша диктовки** — вкладка «Диктовка», выпадающий список как в Voica:
  правый Option (по умолчанию), левый Option, оба Command, Control. Удержание
  пишет, отпускание останавливает; два быстрых нажатия оставляют запись до
  следующего нажатия или галочки. Fn / Globe браузер на Mac не видит.
- **Очистка текста** — слова-паразиты и кавычки-ёлочки, каждое правило отдельно.
- **ИИ-проход** — необязательная правка текста моделью по OpenAI-совместимому
  адресу: падежи, пунктуация, сильно искажённые термины. Сбой прохода не теряет
  расшифровку.
- **Сохранение записей** и срок хранения. Пока запись на диске, сбой
  распознавания не уничтожает сказанное.

## Проверка и разбор проблем

```
alia voice-input status                # движки, Python, ffmpeg, число записей
alia voice-input history 5             # последние расшифровки и пути к аудио
alia voice-input transcribe <путь>     # распознать файл на машине: проверка и разбор старых записей
alia voice-input config                # показать настройки
alia voice-input config engine gigaam  # изменить настройку
alia voice-input download              # скачать модель заранее, с прогрессом
alia voice-input apply-settings        # доставить настройки на машины
```

Записи и лог демона лежат в каталоге данных плагина на машине распознавания —
его печатает `status`. Если VesnALIA жалуется на недоступную транскрипцию, сначала
`status`, затем лог `voiced.log` рядом с записями.

Штатный таймаут голосовой транскрипции в VesnALIA — 10 секунд на попытку; длинная
запись в него не укладывается независимо от движка.


## Редактура и безопасность диктовки

С версии 0.2.14 нужен VesnALIA 0.48.1 / SDK 0.6.104. В «Диктовка» можно включить остановку по тишине и автоотправку; удержание клавиши продолжает запись. Автоотправка привязана к исходному SDK-композеру и неизменённому полному черновику, отключается для ручной и контекстной ИИ-редактуры.

В «Словарь» доступны строгий режим терминов и опциональная редактура по замыслу. Ручной запуск сначала вставляет STT с обычной очисткой; Improve/Undo меняют только последний фрагмент. Полный черновик/история модели не передаются. Модель может ошибиться в смысле: важный текст проверяют перед отправкой. Live preview и штатный рекордер VesnALIA в этом выпуске не включены.
