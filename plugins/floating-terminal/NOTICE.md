# Floating Terminal

Плагин адаптирован для VesnALIA из открытого каталога плагинов bb.

- Оригинальный автор: Vedran Burojević (https://github.com/vburojevic)
- Исходный репозиторий: https://github.com/vburojevic/bb-plugin-floating-terminal
- Каталог в репозитории: (корень)
- Версия: v0.7.0, коммит 5f2b63738cd779a1fd00bb7791db32afa8db4149
- Ссылка на исходник: https://github.com/vburojevic/bb-plugin-floating-terminal/tree/5f2b63738cd779a1fd00bb7791db32afa8db4149
- Лицензия: MIT (текст в файле LICENSE рядом)
- Не перенесены демо-медиа из документации (11 файлов, есть в исходном репозитории)

Изменения VesnALIA: манифест и зависимости переведены на движок alia-core
(раздел `alia`, `@vesnalia/plugin-sdk`), имена bb заменены на имена VesnALIA,
бренд BB в видимых текстах заменён на VesnALIA. Изменения сделаны скриптом
`scripts/adapt.mjs`; список ручных правок и состояние сборки - в STATUS.md.

Авторские права на исходный код принадлежат оригинальному автору.
