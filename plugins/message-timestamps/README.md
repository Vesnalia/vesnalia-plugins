# Message Timestamps for VesnALIA

Shows the time you sent each message next to your bubbles in VesnALIA chat windows.

- Today: `12:43 PM`
- Yesterday: `Yesterday 12:43 PM`
- Older: `Aug 12, 12:43 PM`

Hover the time for the full date. Times come from the thread timeline and are
painted onto the existing chat UI.

## Install

From the VesnALIA Community marketplace once the listing is approved, or directly:

```sh
alia plugin install git:https://github.com/bighitbiker3/bb-plugin-message-timestamps.git@v0.1.0
```

From a local checkout:

```sh
npm install
alia plugin build
alia plugin install .
```
