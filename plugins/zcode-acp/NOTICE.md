# ZCode ACP

Плагин адаптирован для VesnALIA.

- Оригинальный автор: Kirill Vechkasov (https://github.com/ichinya)
- Исходный репозиторий: https://github.com/ichinya/bb-plugin-zcode
- Каталог в репозитории: (корень)
- Версия: v0.1.1, коммит 5725adf2b11ce21b88dbb486df31a2908622a141
- Ссылка на исходник: https://github.com/ichinya/bb-plugin-zcode/tree/5725adf2b11ce21b88dbb486df31a2908622a141
- Лицензия: Apache-2.0 (текст в файле LICENSE рядом)
- Не перенесены демо-медиа из документации (4 файлов, есть в исходном репозитории)

Изменения VesnALIA: манифест и зависимости переведены на движок alia-core
(раздел `alia`, `@vesnalia/plugin-sdk`), имена в коде и бренд в видимых текстах
заменены на VesnALIA. Изменения сделаны скриптом `scripts/adapt.mjs`;
список ручных правок и состояние сборки - в STATUS.md.

Авторские права на исходный код принадлежат оригинальному автору.
