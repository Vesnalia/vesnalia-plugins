# 译稿说明

translations.json 收录用户可见的原文、译文、保留术语及场景摘要。它用于查阅；实际界面以根目录 dictionary.json、template-rules.json、context-rules.json 为准。

按钮使用简洁动词；提示说明发生了什么及下一步；保留删除、覆盖、权限、费用等原文含义。保留技术术语、产品名、命令、URL、路径及动态占位符。相同英文在不同界面的含义不同时，使用场景规则。

翻译由 Claude Sonnet 和 GPT 协助完成，进行了上下文复核。原始 UI 字符串用于界面互操作；本表不包含安装目录、工作流记录或提取时的完整源码片段。
