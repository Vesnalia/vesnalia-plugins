# Save My Model

Плагин адаптирован для VesnALIA.

- Оригинальный автор: Mateo Cerquetella (https://github.com/MateoCerquetella)
- Исходный репозиторий: https://github.com/MateoCerquetella/bb-plugins
- Каталог в репозитории: plugins/save-my-model
- Версия: save-my-model/v0.1.3, коммит f9836254c0286296d36f2b2af4c03cd7160823b8
- Ссылка на исходник: https://github.com/MateoCerquetella/bb-plugins/tree/f9836254c0286296d36f2b2af4c03cd7160823b8/plugins/save-my-model
- Лицензия: MIT (текст в файле LICENSE рядом)

Изменения VesnALIA: манифест и зависимости переведены на движок alia-core
(раздел `alia`, `@vesnalia/plugin-sdk`), имена в коде и бренд в видимых текстах
заменены на VesnALIA. Изменения сделаны скриптом `scripts/adapt.mjs`;
список ручных правок и состояние сборки - в STATUS.md.

Авторские права на исходный код принадлежат оригинальному автору.
